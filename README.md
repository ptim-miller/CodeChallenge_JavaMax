# CodeChallenge_JavaMax
Code Challenge for Java students to find the max value.  

## MISSION: ## 
Main is located in "ComparePerformance", which contains the testing parameters. You can alter the parameters on your local machine for testing but the competition will use 1000x1000 @ 3 iterations per test. You may not be able to use those specific parameters on your local machine, so adjust sizes accordingly for your own testing.  

## RULES: ## 
Other than minor changes to the above listed variables, you should only modify StudentLoops.java. You must change the existing functions in order to determine the max value contained in each data structure. You can only modify the bodies of the 3 provided functions in StudentLoops. Additional imports are acceptable as well. No shortcuts or variable storage of max between structures. You must decide on the best way to search through each data structure as provided. You can use external libraries, such as the Arrays class. You may also take advantage of other parallel methods. Your scores on all 3 searches must be better than the corresponding instructor scores. You must use different iteration methodologies than the instructor's implementations in InstructorLoops.
